# DIP 分组费率查询器（2026 版）

一个纯本地的 DIP（按病种分值付费）病组费率查询工具。输入诊断名称或拼音首字母，即可实时检索 ICD 诊断编码，并按编码规则自动匹配核心病组与综合病组，显示三级分值及职工 / 居民医保付费标准。

## 功能特性

- **智能检索**：支持汉字模糊搜索（≥1 个汉字）和拼音首字母检索（≥2 个字母，如 `jxdny` 匹配"急性胆囊炎"），实时下拉提示，最多显示 50 条候选
- **键盘操作**：↑↓ 键在候选项中移动，回车确认，Esc 关闭下拉框
- **双目录匹配**：
  - **核心病组**：按诊断编码（去除符号后）前 4 位匹配
  - **综合病组**：按前 3 位匹配；未命中时自动按编码首字母类目兜底入组，并给出提示
- **费率自动换算**：根据三级分值实时计算职工医保（×5.69）与居民医保（×4.36）付费标准
- **同组诊断提示**：展示与所选诊断共享前 4 位编码（即同一核心病组）的其他诊断
- **科室入组经验参考**：页面底部内置甲乳血管外科的入组经验文档（下肢静脉曲张、乳房良性肿瘤等常见病的结算标准参考）
- **隐私安全**：纯本地运行，不上传任何数据

## 数据规模

| 数据文件 | 内容 | 规模 |
|---|---|---|
| `data/diagnoses.js` | ICD 诊断编码库（编码、名称、拼音首字母） | 35,723 条诊断 |
| `data/core.js` | 核心病组目录（按编码前 4 位索引） | 2,378 个病组 / 5,669 条病种 |
| `data/comprehensive.js` | 综合病组目录（按编码前 3 位或首字母索引） | 918 个病组 / 2,417 条病种 |
| `data/doc.js` | 科室入组经验参考文档（HTML 片段） | 甲乳血管外科 |

数据来源：湖北 2.0 版 ICD 编码库 · 2026 年 DIP 病组目录。

## 使用方法

### 直接使用（推荐）

无需安装任何环境，直接用 Chrome / Edge 等现代浏览器打开 `index.html` 即可。

### 本地开发预览（可选）

项目附带一个零依赖的 Node.js 静态服务器，仅供开发预览：

```bash
npm run dev                    # 默认 http://127.0.0.1:7100/
npm run dev -- --port 8080     # 指定端口
npm run dev -- --host 0.0.0.0  # 指定监听地址
```

### 查询示例

1. 在搜索框输入 `急性胆囊炎`（或拼音首字母 `jxdny`）
2. 在下拉列表中选择目标诊断（如 `K81.000 急性胆囊炎`）
3. 页面自动展示：
   - 匹配键信息（核心病组键 `K810` ｜ 综合病组键 `K81`）
   - 同组其他诊断列表（可折叠）
   - 核心病组表：各手术/操作组合的三级分值、职工与居民付费标准
   - 综合病组表：兜底类目下的病组及付费标准

## 项目结构

```
├── index.html          # 主页面（样式 + 交互逻辑 + 费率系数配置）
├── server.js           # 零依赖静态服务器（仅开发预览用，日常使用不需要）
├── package.json
└── data/
    ├── diagnoses.js    # ICD 诊断编码库      → window.DIAGNOSES
    ├── core.js         # 核心病组目录        → window.DIP_CORE
    ├── comprehensive.js# 综合病组目录        → window.DIP_COMP
    └── doc.js          # 科室入组经验文档    → window.DOC_HTML
```

## 数据格式

**诊断库**（`diagnoses.js`）：

```js
window.DIAGNOSES = [
  ["K81.000", "急性胆囊炎", "jxdny"],
  // [编码, 名称, 拼音首字母（多音字用全角逗号分隔）]
];
```

**核心病组**（`core.js`，按编码前 4 位索引）：

```js
window.DIP_CORE = {
  "K810": [
    ["K81.0-51.2300", "急性胆囊炎-腹腔镜下胆囊切除术", 3005.282],
    // [病种编码, 病种名称, 三级分值]
  ]
};
```

**综合病组**（`comprehensive.js`，按编码前 3 位或首字母索引）：

```js
window.DIP_COMP = {
  "A09": [
    ["A09-BSZL", "其他传染性和未特指病因的胃肠炎和结肠炎-保守治疗", 1261.633],
  ]
};
```

## 配置费率系数

医保政策调整时，只需修改 `index.html` 中 `<script>` 开头的两个常量，全页面付费标准自动按新系数计算：

```js
const COEF_STAFF = 5.69;     // 职工医保系数（2026 年）
const COEF_RESIDENT = 4.36;  // 居民医保系数（2026 年）
```

修改后保存文件，刷新浏览器即生效。

## 更新数据

病组目录或 ICD 编码库更新时，按上述数据格式重新生成对应的 `data/*.js` 文件并覆盖即可，无需改动页面代码。
